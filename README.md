# E-Commerce Data Engineering Platform

An end-to-end Data Engineering portfolio project focused on building a structured data platform for an e-commerce scenario.

The project is being rebuilt and extended from an academic Data Engineering capstone with an emphasis on understanding, implementing, validating, and documenting each component using professional engineering practices.

## Project Goal

Design and implement a data platform that separates transactional workloads from analytical processing, automates data movement, organizes analytical data using dimensional modeling, and enables business intelligence reporting.

## Planned Data Flow

MySQL OLTP → Python ETL → PostgreSQL Data Warehouse → Power BI

Additional modules explore workflow orchestration with Apache Airflow and distributed data processing with Apache Spark.

## Project Modules

- `01-oltp-database` — Operational sales database with MySQL.
- `02-etl-pipelines` — Data integration, incremental loading, and pipeline orchestration.
- `03-data-warehouse` — Dimensional Data Warehouse implemented with PostgreSQL.
- `04-business-intelligence` — Analytical modeling and reporting with Power BI.
- `05-big-data` — Distributed data processing with Apache Spark and PySpark.
